# assets

Put your CV here as **`cv_source.<ext>`** — any common format works:

- **Word** (`.docx`, `.doc`), **PDF** (`.pdf`), **RTF / OpenDocument** (`.rtf`, `.odt`) — full content *and* styling can be read.
- **Plain text** (`.txt`, `.md`), or just paste your experience into the chat — content is read; there's no styling to inherit, so the skill falls back to sensible defaults you can adjust.
- **A scan or photo** (`.png`, `.jpg`, or a scanned PDF) — read via OCR; content only.

The skill reads this file to learn your career history, profession, and seniority — and, where the format allows, to match your document styling. It is *read*, never edited: your CV stays the source of truth.

If you don't add a CV here, paste your experience into the chat instead.
